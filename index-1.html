Anima

private, on request

Distributed cognitive multi-agent system, eleven specialized modules over an async bus.

  • Risk-classification layer (SAFE / REVERSIBLE / IRREVERSIBLE / FORBIDDEN) gates every action before execution
  • Three-tier memory (episodic → semantic → procedural) with temperature-based consolidation
  • Local LLM inference (Llama 3.1, Qwen 2.5) over Redis, FastAPI + WebSocket observability
